Y además lo haría en este orden concreto:

---

# Fase 1: Profundidad del ramo 🌿

Es la mejora más importante.

## Objetivo

Que el nacimiento de los tallos no sea una línea plana.

Ahora:

```
🌷 🌷 🌷
|||||||
🌿🌿🌿🌿
```

Queremos:

```
    🌷
 🌷     🌷

  🌿🍃🌿
🌱🌿🌱🌿🌱
```

### Qué haremos

* algunas hojas pasarán POR DELANTE de los tallos;
* otras quedarán detrás;
* algunas arrancarán más arriba;
* otras más abajo.

Esto dará muchísimo volumen.

---

# Fase 2: Campanillas orgánicas 🔵

Ahora son lo más artificial del conjunto.

## Objetivo

Pasar de:

```
🔵
🔵
🔵
```

a

```
  🔵
🔵
    🔵
```

### Qué cambia

* cada campanilla tendrá un giro distinto;
* colgarán ligeramente hacia fuera;
* estarán a alturas diferentes.

Parecerán flores reales.

---

# Fase 3: Lavanda más natural 💜

La lavanda ya funciona, pero puede mejorar.

## Objetivo

Que parezca una espiga verdadera.

En lugar de:

```
💜
💜
💜
💜
```

hacer:

```
   💜
 💜💜
💜💜💜
 💜💜
```

Es decir:

* más estrecha arriba;
* más ancha en el centro;
* pequeñas variaciones.

---

# Fase 4: Brisa real 🍃

Aquí ocurre la magia.

Ahora casi todo se mueve igual.

## Objetivo

Que cada planta tenga personalidad.

Por ejemplo:

### Tulipán izquierdo

```css
6.2s ease-in-out infinite
```

### Tulipán central

```css
7s ease-in-out infinite
```

### Tulipán derecho

```css
5.6s ease-in-out infinite
```

### Hierba

```css
8.5s ease-in-out infinite
```

### Lavanda

```css
4.8s ease-in-out infinite
```

### Campanillas

```css
5.2s ease-in-out infinite
```

El resultado es muchísimo más natural.

Cada 4–6 segundos.

0 0 28px gold

Dos o tres motas luminosas.

Muy pocas.
